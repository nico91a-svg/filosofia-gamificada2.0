# Datos privados

Esta carpeta **no se publica** con la aplicación: queda fuera de `web/`, que es
lo único que se compila y despliega.

- `estudiantes-3B-2026.json`: nómina inicial del III Medio B (nombres legales y
  claves iniciales, sin progreso). Antes viajaba dentro del sitio publicado,
  donde cualquiera podía leerla.

## Para qué sirve

Solo como respaldo de emergencia. Los datos vivos (con el progreso real) están
en Firebase. Si alguna vez hubiera que recrear la nómina desde cero:
panel docente → **Importar** → elegir este archivo.

## Importante

Mientras este repositorio contenga datos personales de estudiantes debe
mantenerse **privado**. El archivo también existe en el historial de git de
versiones anteriores.
